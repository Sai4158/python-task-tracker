# Python Task Tracker

A command-line Python learning project built step by step with generative AI.

Planned features:
- Add and view tasks.
- Mark tasks as completed.
- Delete tasks.
- Repeat the menu until the user exits.
- Handle invalid choices and task numbers.

Tasks will be stored in memory only and cleared when the program exits.
No external packages are required.

## Run

```powershell
py task_tracker.py
```
